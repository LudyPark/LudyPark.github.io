Idempotency ≠ retry

Idempotency keeps the same intent from being applied twice. A retry only decides whether to attempt delivery again.

Timeout ≠ failure

A caller timing out only means it stopped waiting. The external operation may still complete and need reconciliation.

Thread dump ≠ CPU profile

A snapshot helps narrow a hypothesis; accumulated CPU and runtime evidence identify sustained work.
